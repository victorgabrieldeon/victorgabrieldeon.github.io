## Direction contract

THESIS: One ruled column, like a spec sheet on graph paper: every block is a panel between full-bleed hairlines, rails run the page height, hatched bands cross the whole window between panels. Refuses the two-column sticky-sidebar portfolio.

OWN-WORLD: Monochrome zinc, white and near-black themes. 1px lines; 315° hatch at 10px. Geist for text, Geist Mono for data only, Caveat only for margin notes and the greeting. Monochrome Simple Icons for languages and tools. Project figures: line diagrams on dotted plates (traço, hachura, tinta). Blue only as the "pushed in the last 7 days" dot.

STORY: Cover figure, avatar, name; info rows and the contribution calendar prove activity; Sobre; the grouped stack, each tool linking to the projects that use it; architecture concepts as diagrams; expand a featured project or go to the projects page; language share as ink bars; open a card, read the project page.

FIRST VIEWPORT: Sticky 56px header in the column (VG mark, Sobre/Stack/Destaques/Linguagens, Projetos page link, GitHub, theme). Cover with isometric extruded VG linework, "Fig. 1."; the identity row overlaps its foot (avatar cell with ring, name row, mono tagline). GitHub button with "me segue" note. Info rows, then the calendar "Fig. 2.".

FORM: Home: hero, link, info, contribuições, Sobre, Stack (one lined row per group: group name + count | grid of tiles with monochrome icon or monogram, name, "em N projetos ↗" when evidenced; empty cells hatched), Arquitetura (two-column lined grid: concept diagram plate "Fig. 3–7", name, one sentence; leftover cell hatched), Destaques (expandable items + "Todos os projetos" button), Linguagens (icon + ink bar rows). Projects page: title with count, lede, filter strip with sliding pill, status line (also shows the stack filter "N projetos com X · Ver todos" from #/projetos?tec=<slug>), two-column lined grid of cards (figure plate "Fig. N", name, summary, kind · language icon · freshness). Project page: back row, figure cover, title, lined meta grid, actions, highlights, command with copy, stack with icons, languages, README, related cards, prev/next. Footer: mark + GitHub, then giant outline wordmark.

SIGNATURE: The cover's linework draws itself on first load and the calendar fills in a wave; each project is identified by its own diagram.

MOTION: That single entrance; View Transition morph from card/featured name into the project title and back; circular theme reveal; FLIP on filtering cards; height ease on expanding items; card hover lifts the plate border and runs the dashed lines; press scale on controls. Reduced motion keeps fades, drops movement.
